2. Zoning type filter

  • Replaced the manufacturing-only sub-filter: every class (Residential, Commercial, Manufacturing, Downtown, Special, Transportation, Unclassified) now expands to specific districts — RS-3, RT-4A, B1, C2, M1, PMD, DX, PD, POS…
  • Tri-state class checkboxes; each class has an “Other” bucket so codes not in the catalogue are never silently hidden.
  • Code: frontend/src/utils/zoningTypes.ts (catalogue + filter builder), map/controls/ZoningFilter.tsx. Added a transportation colour.

3. Building contact list + CSV

  • Select buildings on map mode (or “+ Contact list” in any building popup) toggles buildings into the list; selected buildings get an amber outline above the mask.
  • Owner of record + owner mailing address from Cook County Assessor open data; businesses from Chicago active business licences — both free, keyless, called from the browser (works in static mode).
  • Business phones via backend GET /api/v1/contacts/phone: Google Places (New) first for Chicago, Foursquare fallback (other cities: Foursquare first). Keys stay server-side; results cached; 60 lookups/min/IP limit.
  • All fields editable; hand-entered values survive Retry. List saved per city in localStorage.
  • CSV columns: Name / Address, Building Owner, Contact Name, Phone, Mailing Address — one row per owner and per business; formula-injection safe.
